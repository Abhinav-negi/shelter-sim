ShelterSim, explained from the ground up

The big picture

ShelterSim is one repository (an npm workspaces monorepo) with five app folders and three shared libraries. The product being built is Studio: a React + Vite client (apps/studio) and a Fastify server (apps/studio-server). Two earlier generations are kept frozen: the classic form-based app (apps/client + apps/server), and the first prototype, a Next.js full-stack app (apps/web). Studio is not Next.js: it is a single-page app whose entry is apps/studio/index.html. All of them run the same physics engine.

Technology used, and why

Everything is TypeScript. Versions come from each package.json.

How the codebase is divided

Each box is a workspace (a folder with its own package.json). Studio code is what you'll change. Packages are shared and frozen. The original app is frozen history.
