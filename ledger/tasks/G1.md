# G1 — Typed numeric entry
Status: TODO      Depends on: –      Phase: Studio v2 (`ledger/V2.md` §G1)

## Goal
Every numeric control in the Studio controls panel can be typed from the keyboard (e.g. type `10` into the South
window % instead of dragging), while the slider stays. Includes the orientation dial (azimuth).

## Read
`ledger/V2.md` §G1 · `apps/studio/src/controls/{SliderField,OrientationDial,OpeningsSection,GeometrySection,MaterialsSection}.tsx`
· `apps/studio/src/components/ui/{index.ts,Input.tsx,Slider.tsx,FieldRow.tsx}` · `apps/studio/src/components/ui/Segmented.test.tsx` (test style)

## May touch / must not touch
May: `apps/studio/src/controls/SliderField.tsx`, `apps/studio/src/controls/OrientationDial.tsx`, new
`apps/studio/src/components/ui/NumberInput.tsx` (+ export in `components/ui/index.ts`), new tests next to them.
Must not: store, viewer, routes, server, frozen paths. **No npm install** (`@testing-library/react` + jsdom exist).

## Conditions
1. `SliderField`'s value readout (`SliderField.tsx:45`) is a `NumberInput`: `type="number"`, `inputMode="decimal"`,
   mono, unit suffix shown, accessible label = the field label. Slider and input stay in sync both ways.
2. Keeps a local draft string; commits on Enter and on blur; clamps to `[min,max]`; rounds to `step` (and to
   `decimals` for display); Escape reverts the draft; invalid/empty text reverts without calling onChange; native
   ↑/↓ step works.
3. `OrientationDial` gets the same input for azimuth (−180..180 °).
4. All 7 numeric controls (length, width, height, 3 × thickness, 4 × window %) work through it with no per-caller
   changes beyond what's needed (window % is already in % units: `OpeningsSection` passes ×100).
5. New `SliderField.test.tsx` (testing-library): type `10`+Enter → onChange(10); `999`+Enter → onChange(max);
   `abc` → no onChange, input shows old value; Escape → reverts; blur commits.
6. `npm test -w @shelter/studio` all green (73 before + new), `npm run build -w @shelter/studio` clean, frozen guard empty.
7. Screenshots 1440 + 390, light + dark, of the Studio controls panel showing the inputs; 0 console errors.

## Rules
Units in mono. No layout shift when typing. The input is compact (≈ the old readout's `w-20`). No new dependency.
