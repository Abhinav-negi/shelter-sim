Status: TODO      Depends on: G1, G2 (merged)      Phase: Studio v2 (`ledger/V2.md` §G3)

## Goal
The viewer draws box / cylinder / dome and 1–2 storeys, mirroring the server's facets (what you see is what is
simulated). The Geometry section lets the user pick them.

## Conditions
1. `geometry.ts` returns a shape-tagged `SceneGeometry`. Box = 4-facet ring (unchanged output for a box design —
   existing geometry/Building tests pass untouched). Cylinder = 12-facet ring; `mitreWallEnds` generalised from 45°
   to 180°/N so facets close with no seams. Dome = flat-shaded hemisphere from the same 3 bands × 12 sectors.
2. Windows sit on the facet(s) of each cardinal quadrant (same rule as G2 condition 7). Two storeys = stacked walls,
   a thin intermediate slab and one window row per storey.
3. `framing.ts` fits the camera to the real bounding box (dome height = r; 2 storeys = 2h).
4. `GeometrySection`: shape `Segmented` (Box / Cylinder / Dome); storeys `Segmented` (1 / 2, disabled for dome with
   a hint saying why); "Diameter" instead of Length for cylinder/dome; Width hidden for cylinder/dome; Height hidden
   for dome; a quiet note "Two storeys are simulated as one connected air volume." All inputs use G1's typed entry.
5. Store: setters `setShape`, `setStoreys` (switching to dome forces storeys 1); `loadDesign` normalises missing
   `shape`/`storeys` to box/1 (old saved designs). Store tests cover both.
6. Tests: facet count per shape; ring closure (mitre angle) for N=4 and N=12; dome band areas vs closed form;
   box output unchanged.
7. `npm test -w @shelter/studio`, `npm run build -w @shelter/studio` green; frozen guard empty.
8. Live against a scratch server (:4102) + `vite preview` (:5275): each shape × {1,2} storeys renders and previews
   (results update). Screenshots of box/cylinder/dome and cylinder×2 at 1440 + 390, light + dark; 0 console errors
   (the pre-existing `THREE.Clock` warning is allowed).

## Rules
Keep `frameloop="demand"` and memoised geometry. No CSG library, no new dependency. Match the existing Building.tsx
material/outline style.
