# F2 — ShelterViewer (3D)
Status: TODO      Depends on: F1

## Goal
A view-only R3F scene that renders the current ShelterDesign truthfully and updates immediately on every change.

## Read
`ledger/PLAN.md` (§3D viewer) · `apps/studio/src/design/store.ts` · `apps/studio-server/src/design/types.ts` ·
`apps/studio-server/API.md` (§options: materials/preset constructions, so thickness can be derived)

## May touch / must not touch
May: `apps/studio/src/viewer/**` (+ one demo route if needed). Must not: the store API (ask the orchestrator), server,
frozen paths. **No npm install.**

## Conditions
1. Pure `src/viewer/geometry.ts`: ShelterDesign → dimensions, wall thickness (the construction's `thicknessM`, or the
   preset stack's total when null), window rectangles per facade from WWR, azimuth. Vitest: width 4→6 m makes the
   mesh wider; thickness 0.1→0.2 m makes the walls thicker; azimuth 0→90 rotates the group.
2. The scene has a ground, a flat roof, walls with real openings (no z-fighting), a compass (N marked), and a sun
   direction from date + lat/lon + an hour prop (a small solar-position function). Shadows are on.
3. OrbitControls: orbit, zoom and pan, with a clamped polar angle (it can't go under the ground). No picking, no gizmos,
   no pointer editing.
4. `frameloop="demand"`. It rerenders only on design or hour changes, and geometry is memoised. No console
   warnings.
5. Screenshots of 3 designs (default, wide + thick, rotated 90°). The model reads as architectural and precise:
   restrained materials and neutral light, no toy look.

## Rules
The model reflects only what the physics models. There is no roof-type control and no decorative props.
