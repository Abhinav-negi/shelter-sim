## Conditions
1. Tokens in `src/styles/tokens.css` (CSS variables, light + dark via `prefers-color-scheme` and a toggle): neutrals,
   one accent, the thermal scale, type scale, spacing, 1px rules. Geist + Geist Mono.
2. Routes per PLAN.md, with a `/app/*` guard driven by `GET /api/auth/me` (unauthenticated → `/login`).
3. `src/design/store.ts`: the ShelterDesign, typed setters per control group, `loadDesign`, `reset(defaults)`, and a
   `dirty` flag. Selectors are used so the viewer doesn't rerender on unrelated changes. Vitest covers the setters.
4. `src/api/`: typed fetch wrappers for every API.md route. Errors are normalised to `{code,message,field?}`.
   `import type` only from `@shelter/studio-server`.
5. `npm run build -w @shelter/studio` is clean. `grep -rl "hdkr\|meshTargetDx" apps/studio/dist` finds nothing. Tests
   pass.
6. Screenshot of the shell (light and dark, 1440 and 390 px). It looks calm and intentional, with no banned patterns
   (PLAN.md §Design system).

## Rules
Components are named for product concepts (ShelterViewer, DesignControls…), never PremiumCard/GlassPanel. Keep the
number of UI primitives small (button, input, slider, select, segmented, field row). No shadcn copy-paste dump.
