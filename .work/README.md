# .work/ -- claim ledger

Absence of `.work/<ID>.md` means that task is TODO. Nobody owns it.

Claim with `.work/claim.sh T-18 <owner>`. The task file itself IS the lock --
`claim.sh` uses shell `noclobber`, so a second claim on the same id fails
atomically and leaves the existing file byte-identical.

Never delete a task file to release a claim. To abandon one, edit it in
place: set `status: ABANDONED` and add a one-line reason. A deleted file
loses everything that was learned; a stale ABANDONED file explains why.

`.work/BOARD.md` is generated by `.work/board.sh`. Never hand-edit it --
your edits are lost the next time `board.sh` runs.
