## Deviations and notes for downstream tasks

- `MAT` uses different key names than the pre-existing `M` (e.g. `stone` not `granite`, `steel` not
  `steelSheet`); `M`/`G` are untouched and still exported for the 97 pre-existing tests. T-23/T-62/
  T-63 should key off `MAT`, not `M`, for anything citing LOG.md SS7.11 values.
- `shelterA_stone400`/`shelterB_steelPuf` are built by a private, self-contained `buildC01Shelter()`
  inside fixtures.ts (deliberately NOT importing `test/box.ts`'s `buildBox`, to keep this
  safety-critical fixture from shifting under an unrelated edit to that helper). Both shelters are
  a 4x4x4 m box, uniform `boundary: 'exterior'` on every face (the same proven shape T-04's
  scripts/ci-energy-balance.mjs uses), one 1.5 m^2 south window on `glazingId: 'single'` (from the
  pre-existing `G`), diurnal synthetic weather, `materials: MAT`.
- The module computes `C01_U_A`/`C01_U_B` at import time and THROWS if `U_B > U_A` -- if a future
  edit to `MAT`'s values ever breaks the C-01 validity condition, every test importing fixtures.ts
  will fail loudly at collection time rather than silently producing a meaningless comparison.
- `singleWallSemiInfinite(materialKey, thicknessM)` returns `{ material, mesh, probeNode,
  domainDepth }`: `mesh` is a `WallMesh` built several penetration depths deeper than `thicknessM`
  (so the Dirichlet far boundary can't contaminate the probe), and `probeNode` is the mesh node
  index nearest `thicknessM` from the exterior face. The caller (T-23) drives it with
  `driveWall`/`envelope/response.ts` (sinusoidal `exteriorTemp`, constant `interiorTemp`, no solar),
  reads the exterior node (0) and `probeNode` back with `nodeSeries`, and compares via
  `decrementAndLag` against `analyticalDecrementLag(material.k/(material.rho*material.c),
  thicknessM, periodS)`.
- `adiabaticBox`/`steadyStateBox` reuse the same C-01 scaffold with `rammedEarth` 0.3 m walls (the
  material choice is arbitrary for these two -- they exist to check global energy conservation and
  the steady-state UA balance, not a specific material). `adiabaticBox` sets every surface boundary
  to `'adiabatic'` and `ach: 0` with `allowUnsafeVentilation: true` (the one legitimate use of that
  flag, commented in place). `steadyStateBox` pins auxiliary heating at exactly `qAuxW` by setting
  an unreachable 60 degC setpoint so the heater saturates at `maxPower` every hour.
- Pre-existing, unrelated defect (NOT fixed, outside this task's allow-list, reported per rule 16):
  `tsc -b packages/engine` has two TS2532 errors in `packages/engine/src/solar/shading.ts:60`
  (T-18's file), present on both the pre-T-07 baseline and after this task's changes. Does not
