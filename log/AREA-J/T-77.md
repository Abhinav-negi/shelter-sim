>    `<head>` with the `<link>` tag).

>    `apps/web/app/_pwa-register.tsx` or `apps/web/components/pwa/PwaRegister.tsx`,
>    whichever is inside your allow-list — see below) that contains **only**:
>
>    ```tsx
>    'use client';
>    import { useEffect } from 'react';
>    export function PwaRegister() {
>      useEffect(() => {
>        if ('serviceWorker' in navigator) {
>          navigator.serviceWorker.register('/sw.js').catch(console.error);
>        }
>      }, []);
>      return null;
>    }
>    ```

>    Render `<PwaRegister />` from the layout so it mounts once on every page load.

>    Do **NOT** add any CSS, any `<script>` tag, or any logic other than the single
>    `useEffect`. Do **NOT** import anything from `lib/store.ts`.
>
> 4. No new npm dependencies. The approved list (`log/contracts/00-core.md` §7.13) is closed.
